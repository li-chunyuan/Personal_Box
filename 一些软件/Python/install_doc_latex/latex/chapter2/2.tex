\section{验证安装}

安装完成后，我们需要验证 Python 是否已正确安装并配置了环境变量。

\subsection{打开命令行}
按下键盘上的 \textbf{Win + X} 组合键，呼出系统快速链接菜单。然后按下键盘上的 \textbf{A} 键，或者在菜单中选择“Windows PowerShell (管理员)”（在 Windows 11 中可能是“终端 (管理员)”）。

这将打开 Windows PowerShell 窗口，它比传统的 cmd 命令提示符功能更强大。

\subsection{检查 Python 版本}
在命令行中输入以下命令并回车：

\begin{lstlisting}[language=bash]
python --version
\end{lstlisting}

或者：

\begin{lstlisting}[language=bash]
python -V
\end{lstlisting}

如果安装成功，你将看到类似 \texttt{Python 3.10.0} 的版本号输出。

如果提示 \texttt{'python' 不是内部或外部命令}，则说明环境变量未配置正确，可能需要重新安装并勾选 \textbf{Add Python to PATH}，或者手动添加环境变量。
