# 开箱即用的LaTeX 通用笔记模板 (基于 DJTU)

## 🛠️ 必备工具清单

本模板依赖以下环境，请在使用前安装：

1.  **Visual Studio Code (VS Code)**：[官网下载](https://code.visualstudio.com/)
2.  **TeX Live** (推荐 2024 或更新版本)：[官网下载](https://www.tug.org/texlive/) / [清华大学镜像站](https://mirrors.tuna.tsinghua.edu.cn/CTAN/systems/texlive/Images/) (国内推荐)
3.  **LaTeX Workshop** (VS Code 插件)：在 VS Code 扩展市场中搜索并安装。

## 1. 模板格式说明

本模板基于 `ctexart` 文档类，预设了符合一般学术笔记或报告的排版格式。以下是详细的格式设置参数，方便您快速了解并根据需求在 `latex/config.tex` 中进行修改。

### 1.1 页面与字体
*   **纸张大小**：A4
*   **页边距**：上下左右均为 2.5cm
*   **正文字体**：
    *   中文：宋体 (SimSun)
    *   英文/数字：Times New Roman
    *   字号：小四 (12pt)
*   **行距**：固定行距 20pt

### 1.2 页眉页脚
*   **页眉**：居中，宋体小五号，显示当前章节标题，下划线宽 0.5pt。
*   **页脚**：居中，宋体小五号，显示页码。

### 1.3 章节标题格式
*   **一级标题 (Section)**：三号黑体，居中，段前 30pt，段后 20pt。
*   **二级标题 (Subsection)**：四号黑体，左对齐，段前 25pt，段后 12pt。
*   **三级标题 (Subsubsection)**：小四号黑体，左对齐，段前 12pt，段后 6pt。

### 1.4 目录格式
*   **标题**：“目    录”（中间空了两格）
*   **显示深度**：显示到二级标题 (Subsection)
*   **一级条目**：黑体小四号
*   **二级条目**：宋体小四号，缩进 2em
*   **引导线**：点状引导线

### 1.5 参考文献格式
*   **标准**：GB/T 7714-2015 (`gb7714-2015` 样式)
*   **排序**：按引用顺序排序 (`sorting=none`)
*   **字体**：宋体五号
*   **后端**：Biber

## 2. 项目结构说明

本项目采用模块化结构，保持根目录整洁，便于管理长文档。

*   **`main.tex`**：**项目入口文件**。负责整体架构，包含文档类设置、引入配置文件、组织各个章节顺序。通常不需要在此处写大量正文。
*   **`latex/`**：**核心源码目录**。
    *   `config.tex`：**全局配置文件**。所有的宏包加载、页面设置、字体设置、命令定义都在这里。
    *   `cover/cover.tex`：**封面文件**。修改此文件以自定义封面内容（标题、作者、日期等）。
    *   `chapterX/` (如 `chapter1/`)：**章节内容文件夹**。建议将每一章的内容单独放在一个文件夹中，便于管理。
*   **`bib/`**：**参考文献目录**。
    *   `ref.bib`：参考文献数据库文件（BibTeX 格式）。
*   **`figures/`**：**图片资源目录**。建议将文档中用到的所有图片都存放在此目录下。
*   **`out/`** (编译后生成)：通常小白不需要在意此文件夹中的内容，里面存放编译过程中产生的中间文件（如 `.aux`, `.log`）和最终的 PDF 文件。
*   **`.vscode/`**：包含 VS Code 的项目配置文件 (`settings.json`)，用于配置 LaTeX 编译工具链和清理规则，实现开箱即用。

## 3. 快速上手指南 (从 0 开始)

### 第一步：环境准备
1.  安装 **TeX Live** (推荐 2024 或更新版本)，设置环境变量。
2.  安装 **Visual Studio Code (VS Code)**。
3.  在 VS Code 中安装 **LaTeX Workshop** 插件。
4.  **应用项目配置** (任选一种方法)：
    *   **方法一：全局配置 (推荐)**
        *   适合希望以后打开任何 LaTeX 项目都能自动应用此配置的用户。
        *   在 VS Code 中按下 `Ctrl + Shift + P`，输入 `Preferences: Open User Settings (JSON)` 并回车。
        *   打开本项目文件夹 `.vscode/settings.json`，将其中的内容复制，粘贴到刚才打开的全局 `settings.json` 文件的大括号 `{ ... }` 中（注意合并 JSON 内容，不要破坏原有格式）。
    *   **方法二：项目独立配置 (已内置 - 开箱即用)**
        *   本项目根目录已包含 `.vscode` 文件夹，内置了所有必要的编译和清理配置。
        *   **您无需进行任何手动配置**，直接打开项目即可开始写作和编译。
    *   *这一步非常重要，它包含了自动清理中间文件和正确编译中文文档的关键配置。*

### 第二步：开始写作
1.  **修改封面**：打开 `latex/cover/cover.tex`，修改标题、作者名为你自己的信息，或者导入你自己想用的封面
2.  **编写正文**：
    *   在 `latex/` 目录下新建章节文件夹（如 `chapter6/`）和 `.tex` 文件。
    *   或者直接修改现有的 `latex/chapter1/1.tex` 等文件。
3.  **组织章节**：打开 `main.tex`，使用 `\include{latex/chapterX/filename}` 命令将你写好的章节文件引入到主文档中。
4.  **添加引用** (可选)：
    *   将参考文献信息（BibTeX 格式）复制到 `bib/ref.bib` 文件中。
    *   在正文中使用 `\cite{key}` 命令进行引用。

### 第三步：编译生成
1.  打开 `main.tex` 文件。
2.  点击 VS Code 左侧侧边栏的 LaTeX 图标，点击 "Build LaTeX project"。
3.  或者直接按 `Ctrl + S` (默认快捷键) 进行编译。
4.  编译完成后，点击右上角的预览按钮查看生成的 PDF。
